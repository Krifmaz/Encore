## Encore 0.42.19

### Fixes

* **Update now is safe again.** 0.42.17 and 0.42.18 were built from old code and can't open databases from
  0.42.11 or newer: Update now rolled back to the running version and said only "the update did not go
  through". This release is built from current code; update to it from 0.42.11–0.42.16 as usual.
* **Update now refuses a release that would not open your database**, before anything is downloaded or
  stopped, and says why.
* **Diagnostics → Updates shows which step of a failed update went wrong**, with the error and a Copy button
  for the whole step-by-step record.
* Once a new version has begun migrating the database, a failed start no longer rolls back to the old version
  (which might not read it): the new one is started again, and the backup taken before the migration stays in
  /config/backups.
