## Encore 0.37.1

**Drag and drop for every upload, and search in the file manager.** Drop files on any upload instead of using its
file chooser, and find any file or folder by name from Settings → System → Files.

### Drag and drop
- **Website**: *Upload plugin*, the Apple Music app on the wrapper card, *Upload a backup…*, your profile picture,
  *Change artwork*, a .txt list in *Import playlist* (*Paste a list*) and bug report attachments (new report and
  reply). The file manager keeps its own drop with folders.
- **Desktop app**: the same uploads, plus the *Convolution* impulse response file.
- While files are dragged over the window every place that takes them gets a dashed outline, and the one under
  the pointer lights up.
- A drop is checked like a picked file: the same file types, and only one file where the upload takes one (the
  first is used and a toast says so). Attachments take several files at once.
- A file dropped beside an upload no longer opens in the browser tab and leaves Encore.

### Files: search (web, desktop and Android)
- **Type to filter** the folder that is open: only the files and folders whose names hold every word you type stay
  in the list (any order, any case). Select all, Move and Move to trash act on what is shown.
- **The whole root is searched too.** When you stop typing, Encore looks through every folder of the root you are
  in (the library, staging, a download folder) by name and lists what it finds under the folder's own rows, the
  nearest first, each with the path of the folder it is in. Accents don't matter ("beyonce" finds "Beyoncé").
- **Click a result** to open its folder with the file picked, or to open the folder itself. The search box empties
  when you open another folder.
- Web and desktop: **Ctrl+F** (⌘F) or **/** on the list goes to the box, **Esc** clears it, **Enter** picks the first
  match (or opens the first result when the folder has none); on the web **↓** moves from the box into the
  results.
- On the web, in the Trash the box filters the trash's list.
- For apps and scripts: `GET /api/files/search?root=&path=&q=&limit=` (admins), written down in
  docs/contracts/client-shapes-0.31-0.33.md §4.18. A link is found by its name but never followed, and Encore's
  config folder is never searched.
