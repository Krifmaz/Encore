## Encore 0.26.2

*(Never published: its release job failed on a GitHub permission error. Everything below shipped in 0.26.3.)*

- **Pages that never finished loading are fixed** (the Library grid stuck on placeholders, Requests spinning, an artist's Discography showing a count but no tiles, library albums on the artist page that would not open or play). One bug behind all of it: drawing a tile whose title starts with multi-byte characters (Japanese, Korean, curly quotes, "…") crashed the page's WebAssembly, and everything after that stopped. Reproduced with a library holding "ペルソナ4 サウンドトラック"; any such album, artist or request title set it off.
- **The web app now says when it breaks.** A red banner names the error with a Reload button, and the report is filed under Settings → Diagnostics → App crashes (kind "Web page") instead of leaving a half-drawn page to guess at.
- **Lyrics button on the player bar**, next to Up next. View album, Add to playlist and Share as bar buttons, with a way to choose what sits on the bar, come next.
- Server image only; the desktop and Android apps are the 0.26.0 builds. After `docker compose pull && docker compose up -d`, reload the web app once.
