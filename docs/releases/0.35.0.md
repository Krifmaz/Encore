## Encore 0.35.0

A **Surround library** for Dolby Atmos and other multichannel (5.1, 7.1) versions of songs. It sits apart from the
stereo library, with its own folder, tab and album pages, and each surround album links to its stereo album and
back. Apple Music's Dolby Atmos versions come in through the gamdl plugin.

### New since 0.34.0
- **The Surround folder**: `/music/Surround` by default (Settings → Library → Surround (Dolby Atmos), *Surround folder*). Encore
  scans it as a library of its own. Surround files never show in the stereo library's lists, search, shuffle,
  radio, playlists, likes, stats, duplicates or media-server sync. Encore reads each file with ffprobe for its codec,
  channels, layout and Dolby Atmos, and links each album to its stereo album by name, then ISRC, then track number
  and title.
- **The Surround tab** in the library on the website, Android and desktop lists the surround albums with their
  format (Dolby Atmos, E-AC-3 5.1, FLAC 7.1 and so on). Everyone sees and plays them.
- **Get Dolby Atmos version** (admins) on a stereo album page, and in a song's ⋯ menu, asks Apple Music for the
  Atmos version and downloads only that into the Surround folder. The stereo copy stays. If Apple has Atmos for
  only part of an album, you get the part that exists. A stereo album shows its surround version as a link, and a
  song with one has *Play the surround version*.
- **Fetch Dolby Atmos automatically** (*Fetch the Dolby Atmos version after each request*, off by default):
  after a stereo album or song request completes, Encore checks Apple Music and requests the Atmos version when
  there is one. Each album is checked once a week, and an album with no Atmos version is asked again after two days.
- **A 5.1 or Atmos file in a stereo download** goes to the Surround library, and the stereo request keeps looking
  for a stereo copy.
- **Playback**: browsers get the surround songs as multichannel FLAC, because no browser decodes E-AC-3. A player
  that says it decodes the codec (the `x-encore-decoders` header) gets the original file. Kodi, Plex or Jellyfin can
  read `/music/Surround` as a library of their own. Encore writes `.plexignore` and `.ndignore` lines so a stereo
  Plex or Navidrome library over `/music` leaves it out (*Hide the Surround folder from stereo media-server libraries*, on by
  default).
- **gamdl**: the *Dolby Atmos* choice of *Format* moved to the Surround library. An Atmos request downloads Atmos
  only, with no AAC fallback.

### Before you update
- **Schema 30** adds the `surround_tracks` and `surround_checks` tables and a `class` column on requests. It migrates
  by itself, and your stereo library is not touched.
- **gamdl set to Dolby Atmos?** Its stereo downloads are now ALAC, falling back to AAC. Atmos goes through the
  Surround library instead.
- **Atmos needs a wrapper-v2 server** set on the gamdl card. Without one, *Get Dolby Atmos version* says so and
  nothing is downloaded.
- **Surround files you already have**: put them under `/music/Surround/<Artist>/<Album>/` and press *Scan*.
- **Coming next**: 0.36 passes E-AC-3 Atmos over HDMI from the Android app, and plays 5.1 and 7.1 on web and
  desktop. 0.37 adds Cadenza bitstreaming to the receiver. 0.38 adds more surround sources (Soulseek and indexers)
  and *Import into Surround* in the file manager. The plan is in docs/backlog/2026-10-surround.md.
- **Not checked against Apple Music before release**: the build machine could not reach it. Try *Get Dolby Atmos
  version* on one album that Apple marks Dolby Atmos first.
