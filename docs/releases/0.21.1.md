## Encore 0.21.1

- **Tidal sign-in for downloads is done by Encore itself** instead of through streamrip, with browser-like headers. Two steps (Tidal uses one client for 16/44.1 FLAC and another for hi-res); the tokens land in streamrip's config. When Tidal blocks the server's address (an HTML 403 page, common for hosting and VPN addresses) the message says so, and a **Paste tokens instead** box takes the `[tidal]` section from a streamrip sign-in done on your own computer. **Sign out of Tidal** link. Diagnostics says whether Tidal can be reached from the server.
- **Plex sign-in works on phones**: a dialog with an *Open Plex sign-in* button and a wait indicator instead of a popup that mobile browsers block.
- **Spotify / Tidal connections**: when the Public URL or the Client ID is missing, a dialog explains it and shows admins the exact redirect URI to register at the service. A refused sign-in comes back to the Connections page with the service's reason instead of an error page.
- **YouTube Music**: with no Google OAuth client configured, Connect goes straight to the paste-your-browser-headers path.
