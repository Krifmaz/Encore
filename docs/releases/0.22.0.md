## Encore 0.22.0 – a VPN for Soulseek, built in

### Highlights
- **VPN for Soulseek**: Encore now has WireGuard built in and sends only Soulseek through it. Tidal, Qobuz, Deezer, Spotify, metadata and the web UI keep your normal connection, so streaming services no longer refuse a VPN address.
- **Fill it in from Settings**: *Settings → Apps & sources → Soulseek → VPN for Soulseek*. Turn on *Send Soulseek through a VPN* and paste the WireGuard `.conf` file from your VPN provider (ProtonVPN: *Downloads → WireGuard configuration*, with NAT-PMP port forwarding on). The private key stays on your server and is never shown again.
- **Port forwarding**: with NAT-PMP (ProtonVPN), the port the VPN forwards becomes the Soulseek listen port and is followed when it changes.
- **Kill switch**: *Keep Soulseek off while the VPN is down* (on by default) stops Soulseek from connecting directly when the tunnel is not up.
- **Status**: the card shows *Connected · port · public IP · last handshake*, and *Test VPN* checks it on demand. Diagnostics has a VPN row too.

### Upgrading from gluetun
No gluetun, `NET_ADMIN` or tun device needed, and no Soulseek port to publish – the VPN forwards it:

```yaml
  encore:
    image: ghcr.io/krifmaz/encore:latest
    environment: [PUID=1000, PGID=1000, TZ=America/Detroit, ENCORE_LIBRARY_PATH=/music]
    ports: ["8080:8080"]
```

Move Encore out of gluetun's network, paste your WireGuard config in Settings (or set `VPN_ENABLED=true` and `VPN_WIREGUARD_CONFIG`), and remove `SOULSEEK_PORT_FILE`.
