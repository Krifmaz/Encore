## Encore 0.22.1

- **Download tools update themselves – no new Encore image needed.** Settings → Apps & sources → *Download tools* shows yt-dlp and streamrip with their versions, *Check for updates*, and *Update to X*. Updates go into `config/tools`, so they survive pulling a new image; when an image ships a newer copy, that one is used. *Use the bundled version* undoes an update.
- **Daily automatic updates** (Scheduled tasks → *Update download tools*), with a switch each for yt-dlp and streamrip.
- The built-in Soulseek client is listed too: it is part of Encore and updates with it.
