## Encore 0.35.1

**streamrip downloads from Deezer, Qobuz and Tidal at the same time.** Each service now has its own line,
one download at a time, instead of one line for all three: a Deezer album no longer waits behind a Qobuz one.
Two downloads never run at once on the same account, so nothing changes for what each service sees.

### What runs at once
| Source | At once |
|---|---|
| streamrip | 1 on Deezer, 1 on Qobuz, 1 on Tidal (each album's tracks still download in parallel inside streamrip) |
| yt-dlp | 2 |
| Torrent and Usenet searches | 2 (the downloads themselves: as many as qBittorrent or SABnzbd allows) |
| Soulseek searches | 1 (slskd allows one; downloads from different users run at once) |
| Each plugin (zotify, gamdl, uploaded ones) | 1 |

The limits that stay are there to keep accounts safe: several downloads at once on one Spotify, Apple Music or
Deezer sign-in, or many on YouTube, is what gets accounts flagged.

### Also
- streamrip's lookups (Encore's own searches on Deezer and Tidal) still run one at a time, and no longer wait
  behind a download.
- Encore no longer rewrites streamrip's `config.toml` when nothing in it changed, so a Deezer run starting can't
  undo the Tidal tokens a running Tidal download is saving.
