## Encore 0.37.0

**Apple Music in ALAC and Dolby Atmos, set up from the Plugins page.** gamdl needs a *wrapper* for lossless and
Atmos: a small service signed in to your Apple Music account that decrypts for it. The new **Apple Music wrapper**
plugin builds and runs one for you, signs it in, and fills in gamdl's Wrapper URL.

### Apple Music wrapper (new plugin)
- **Install it under Settings → Plugins**, next to gamdl. It runs
  [wrapper-v2](https://github.com/glomatico/wrapper-v2), the wrapper gamdl 3.9 speaks to.
- **Encore runs it (the default).** Mount the Docker socket into Encore
  (`- /var/run/docker.sock:/var/run/docker.sock`, the same one "Update now" uses), **Upload app** (your own copy of
  Apple Music for Android 3.6.0-beta, build 1109, as an `.apk` or APKMirror `.apkm`), press **Set up**. Encore
  downloads wrapper-v2's source, takes the Apple libraries out of the app (a different app version is refused
  before the build, by the checksums wrapper-v2 pins), builds the image on your Docker and starts it as the
  container `encore-wrapper` beside Encore's, on Encore's own Docker network. The first build takes 10 to 30
  minutes; the card shows each step and the plugin's log has every build line.
- **A wrapper I run.** Already have a wrapper-v2? Enter its address instead; everything below works the same.
- **Sign in on the card** with your Apple ID and password, then type the code Apple sends to your iPhone, iPad or
  Mac. The password goes to the wrapper only: Encore keeps it nowhere. The session survives restarts and rebuilds
  (it lives in the Docker volume `encore-wrapper-data`).
- **gamdl fills itself in**: when the wrapper starts or signs in, gamdl's Wrapper URL and decrypt address point at
  it (or press **Use with gamdl**). Then pick **ALAC lossless** on the gamdl card, or Get Dolby Atmos version for the
  Surround library.
- **Start, Stop, Build again, Wrapper log and Test** on the card. Test checks that the wrapper answers, speaks the
  API gamdl needs, loaded Apple's libraries and is signed in.
- Needs an **Apple Music subscription**. Details, limits and how to build the image elsewhere (arm64 servers need
  QEMU for the build): [docs/plugins/WRAPPER.md](https://github.com/Krifmaz/Encore/blob/ccr-a4585b2e-d7xdtf/docs/plugins/WRAPPER.md).

### Before you update
- Nothing to do. The wrapper container gets the privileges wrapper-v2 needs (`SYS_ADMIN`, `SYS_CHROOT`,
  `SYS_PTRACE`, no AppArmor profile); Encore's own container keeps none of them.
