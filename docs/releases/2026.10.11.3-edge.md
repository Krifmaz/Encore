## Encore 2026.10.11.3-edge

### Fixed
- **qBittorrent login**: works with qBittorrent 5.1+, which renamed its login cookie. The test now shows the real reason when a login fails (wrong password, IP ban, host-header check).
- **streamrip "not installed"**: the image now always contains streamrip. If the preferred build can't be installed it falls back to the official one, and the build stops instead of quietly shipping without it.
- **YouTube downloads failing with "Requested format is not available"**: Encore retries as other YouTube clients, without cookies, and on the other YouTube host. The image also includes Node.js, which yt-dlp now needs for YouTube.
- **False "wrong audio" rejections**: a Japanese title vs its romanized spelling, or an instrumental that AcoustID files under the vocal version, is no longer rejected.
- **ListenBrainz "token is not valid"**: Encore now always identifies itself properly to MetaBrainz, and shows ListenBrainz's own reason if a token is refused.
- **Artist photos missing on For you / similar artists**: Deezer requests are paced and retried, and a temporary failure is no longer remembered for a week. Photos load in the background, so pages appear at once.

### Changed
- **One search order**: Settings → Downloads & sources → Download pipeline → *Source order* is the only place to choose what is searched: `qobuz, tidal, deezer, slskd, torznab, ytdlp`. The separate streamrip service list and the Auto-download copy are gone.
- **HiFi API / Monochrome removed**: streamrip handles TIDAL.
- **For you**: adds *Albums for you*, and *Songs for you* now comes right after the artists.
- **Account page**: *Change password* sits under your profile.
- **Owner** is shown in the sidebar and the Users list (and profile pictures show in the list).
