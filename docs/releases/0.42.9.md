## Encore 0.42.9

**Tagging a single shows the right confidence.** In "Tag this album", a single whose song is tagged with the
release's name (">one (greater than one)") and no track number scored about 41% against its own MusicBrainz
release, which names the song shorter (">one"). An exact match like that now scores 95% or more.

### Details
- For one file against a one-song release, the file's title is also compared with the release's title, and a
  missing track number no longer costs anything (there is no order to get wrong).
- Every release also compares titles without their bracketed or " - …" parts, a little lower than an exact
  title, so on a release with both "Song" and "Song (Remix)" each file still lands on its own song.
- Server only: no app update needed.
