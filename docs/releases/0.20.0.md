## Encore 0.20.0

First release with plain version numbers (no more date versions, no more "edge"): every build is a normal release, `:latest` always means the newest one, and Obtainium follows it the usual way.

- **New Android app**, written natively (Kotlin): sign in once and stay signed in (your phone shows up under Account → Sessions, where you can sign it out), home, library, albums, artists, playlists, liked songs, search, a full-screen player with the album-art backdrop, Up next, lyrics, share links, the Signal path, the quality badge, Discover, For you, Requests with the picker, playlist editing, the Account page and the Leaderboard. Playback runs on the phone itself: gapless, lock-screen and notification controls, Android Auto (with a proper "Sign in to Encore on your phone" message instead of "can't use this app"), *Auto* quality that adapts to the connection, *Data saver* and *Original*, the EQ / crossfeed / balance / mono effects and the Cadenza engine built in. Looks like the web player, in the Encore charcoal-and-cream theme. It installs over the previous app from now on (permanent signing key).
- **Database safety**: Encore now keeps copies of its database (daily, and before every upgrade) in `config/backups`; Settings → Diagnostics → Backups lists them with Back up now, Download, Restore and Upload. A server that is older than the database it finds refuses to touch it and says so, instead of breaking.
- **Just Encore**: the "Encore 2 / (Rust)" labels are gone from the app, README and docs.
- **Releases**: versions are MAJOR.MINOR.PATCH; starting a release asks which number to bump; "only: android" rebuilds just the APK.
- **Download order**: new installs search Qobuz, Tidal, Deezer, Soulseek, torrents/Usenet, then YouTube Music. Sources you haven't set up are skipped; a saved order is kept.
- Desktop app: follows http→https redirects and sign-in portals instead of opening the browser; its own pages use the Encore colours.
- Web player: the full player bar is always shown (devices on the far right), Space is play/pause even after clicking a player button, the quality badge opens the Signal path, Account has a pencil to rename and a Change-password button, the Settings tab list scrolls all the way down.
- Songs in formats a browser can't play (DSD, APE, WavPack …) play again on the website.
