## Encore 0.21.0

- **Cadenza is built into the desktop app.** Install the Encore app on the computer connected to your DAC and sign in: the app signs its engine in on its own (an *Encore app* session under Account → Sessions), the engine shows up under *Your devices* as *This computer (Cadenza)*, and this window links to it by itself. Music then plays through Cadenza straight into the DAC while the window shows the normal Encore app. Unlink it under *Your devices* to play through the browser audio again; link it again to turn it back on. The engine's settings live in `<config dir>/cadenza/config.toml`.
- **Cadenza v2 engine**: exclusive output on Windows (WASAPI), macOS (Core Audio) and Linux (ALSA), DSD output up to DSD2048 (native or DoP, with a choice of modulators), GPU processing on NVIDIA cards (Linux and Windows), channel matrix presets, headroom and a soft clipper.
- **Settings → Playback → Cadenza engine** now shows every switch of the linked engine: output device, exclusive mode, bit-perfect, PCM or DSD output, upsampling filter, dither and noise shaping, output rate and bit depth, DSD rate, modulator, packing, oversampling and gain, headroom (automatic or by hand), soft clipper, GPU (Auto, On, Off, with the card in use), matrix, and a status line with the output in use and any error. The same section works for a standalone `cadenza serve` linked under *Your devices*.
- **Signal path**: for a Cadenza device every stage the engine ran is listed (decode, upsampling, dither, DSD modulation, GPU, output), plus whether the output is exclusive and bit-perfect.
- **Server**: `POST /api/auth/app-token` hands a signed-in browser a bearer token for a named device (used by the desktop app's engine); re-issuing for the same device replaces the old token. `/api/auth/info` lists the `engine_token` feature.
