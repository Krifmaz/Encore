## Encore 0.27.0

- **A new desktop app for Windows, macOS and Linux.** Native and written in Rust, with no web view inside: the same pages, words and buttons as the web app, and every song plays through Cadenza, Encore's playback engine, built into the app. Settings → Playback → *Play through Cadenza on this device* turns the engine's processing on for your DAC: the output device, exclusive mode (with "Exclusive mode failed: <reason>" instead of falling back to shared without a word), PCM and DSD rates limited to what the device takes, DSD greyed out in shared mode, a link limit for USB, I2S and S/PDIF, filters, dither, EQ, *Test sound* and the full signal path. Switched off, the engine plays the file bit-perfect. The computer is one device in Your devices ("Encore on <computer name>"): the phone and the browser can send music to it, and it can send music to them.
- Around the window: tray, media keys and the system media controls, a mini player, global shortcuts, start with the computer, songs saved for offline, and updates from the GitHub release (the download is checked against the release's `SHA256SUMS` before it is installed). Download `Encore-0.27.0-windows-x86_64.exe` (installs for your user, no administrator rights), `Encore-0.27.0-macos-universal.dmg`, `Encore-0.27.0-linux-x86_64.AppImage` or `encore_0.27.0_amd64.deb`. The first start asks for your server and your sign-in; nothing is carried over from the old app.
- **The classic desktop app (Tauri) is built one last time** under its old file names (`Encore-Setup-0.27.0.exe`, `Encore-0.27.0-mac.dmg`, `Encore-0.27.0-linux-amd64.deb`, `.rpm`), except its AppImage, which is now `Encore-classic-0.27.0-linux-x86_64.AppImage`. On Windows and Linux the two apps can be installed side by side; on macOS the new Encore.app takes the old one's place in Applications. Side by side, both are called Encore: Apps & features and the Linux app menu list two Encore entries, and the Windows Start menu shortcut opens the one installed last. To remove the classic app on Windows, run `uninstall.exe` in its folder (`%LOCALAPPDATA%\Encore` unless you chose another; the new app's uninstaller there is `uninstall-encore-desktop.exe`). This is the classic app's last release: move to the new one.
- **The JavaScript web UI is gone.** The Rust/WebAssembly app at `/` is the web UI, as it has been since 0.26.0; the old files are no longer in the image. `ENCORE_LEGACY_UI` and `ENCORE_LEGACY_STATIC_DIR` do nothing any more and can go from your compose file. `/next/` still redirects to `/`.
- **Codec negotiation for players that cannot decode everything.** A player that says what it decodes (`X-Encore-Decoders: flac,mp3,aac,alac,opus,vorbis,wav,aiff,dsf,dff`, or the same list as `?codecs=` on the stream URL) gets the original file when its codec is listed – DSF and DFF included, so a player that lists them gets the DSD file itself instead of PCM – and a lossless FLAC transcode at the same sample rate and bit depth otherwise. The `x-encore-stream` header says which (`original`, `flac`, `flac-fallback`), and `GET /api/library/tracks/{id}/info` reports the same decision under `stream: {kind, codec, reason}`, so a signal path can read "converted to FLAC because the engine has no Opus decoder". Browsers and the phone app are not affected: without the header the stream is served as before.
- **The YouTube status shims announced in 0.26.0 are removed**: the `managed` name for the hand-off, `next_check` in the status (use `next_refresh`) and the old-browser clean-up.
- **The web player's code is reorganised** into smaller files with no visible change: same pages, buttons, shortcuts and saved settings. If something in the player behaves differently from 0.26.8, that is a bug; please report it.
- For developers: the work the Cadenza engine needs for "Play through Cadenza on this device" (Opus, exclusive-mode errors in plain words, device capabilities, the decoders header) is written up in `docs/cadenza/2026-10-engine.md`. The new desktop app above is built on it.
