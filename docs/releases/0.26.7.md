## Encore 0.26.7

- **"Check for updates" no longer runs into GitHub's rate limit.** Encore now asks GitHub conditionally (an unchanged answer costs nothing against the limit of 60 requests an hour per address) and keeps the last answer for each tool. When the limit is hit anyway, the message says when it clears instead of quoting GitHub.
- **GitHub token (optional)** under Settings → Apps & sources → General, or the `GITHUB_TOKEN` environment variable: raises the limit to 5,000 an hour. A fine-grained token with no permissions is enough.
- Server image only; the desktop and Android apps are the 0.26.0 builds. Reload the web app once after updating.
