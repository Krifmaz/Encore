## Encore 2026.10.12.4-edge

- **Stutter-free playback, adapting to your connection**: Settings → **Playback** (per account). *Auto* plays the original file and measures the connection while it plays (download speed, a small probe, and the browser's own estimate). It steps the stream down as far as it needs to keep the music playing – 256, 160, 96, 64, down to 32 kbps AAC/Opus – and back up as soon as the connection allows, at the next song or mid-song once there's headroom. *Original* never converts; *Data saver* always uses the small stream (AAC 96 kbps, Opus in browsers without AAC). The next song is pre-loaded once the current one is safely buffered, anything the browser can't decode (ALAC, APE, WavPack, AIFF, WMA, DSD) is converted losslessly up front, and audio is never gzip-compressed any more.
- **Sound on this device**: Settings → Playback → *Sound (on this device)* – parametric EQ (presets or up to 10 bands, preamp), headphone crossfeed, balance and mono, plus crossfade (0–12 s) with an optional *Keep albums gapless*. All of it runs in your browser or app, so it costs the server nothing; the Signal path lists what's on.
- **Signal path**: the quality badge on the player opens a window with three rows – the file (codec, bit depth, sample rate, channels, bitrate), what Encore sent (the untouched file, FLAC, or a lossy stream and why) and what this device does with it (its output rate, and a warning when the system resamples) – and a plain verdict on whether you got the untouched file. Linked remotes show what the other device reports.
- **Instant remote control**: devices keep an event stream open to the server, so commands reach the other device and its state comes back the moment things change (about a tenth of a second instead of up to two). The player checks in right away on play/pause/seek/volume/track changes.
- **Full-screen player while linked**: tapping the song while remote-controlling opens the full-screen view for the other device, with a *Playing on …* device picker, like, share and a ⋯ menu (Go to artist, View album, Add to playlist, Lyrics, Share link, Download, Signal path, Your devices). The same like/share/⋯ buttons sit on the bar and in the full-screen view for local playback, and "Up next" lets you jump within the other device's queue.
- **Layout sizes to the screen**: the Comfortable/Full-width choice is gone – pages take the full width on phones, about 1180 px on laptops and more on big monitors. On phones the bar keeps play, next, Up next and ⋯; everything else lives in the full-screen player, within thumb reach.
- **Shared songs carry metadata**: `/s/<token>` links now have Open Graph / Twitter tags (title, artist, album, cover, duration, quality) so chat apps show a proper preview, and the share page lists the format, bit depth / sample rate or bitrate, and length.
- **Who requested it, and when**: the album page shows *Requested by … on <date> · added <date>* (and per track on its source line).
- **Android Auto**: the Android app is now a car media app. Browse Recently added, Recently played, Made for you, Playlists, Liked Songs, Albums, Artists and *Shuffle everything* on the car screen, ask for songs, albums or artists by voice, and play straight from your server (the car can start Encore with no screen open). Plays and now-playing are reported like the web player, so Last.fm/ListenBrainz keep scrobbling, and the car player shows up under *Your devices* as "Car · <phone>" – push a queue to it from any browser. Side-loaded APKs need Android Auto's *Developer settings → Unknown sources* once (see the README).
- **Server processing with Cadenza (optional, off by default)**: Settings → Apps & sources → *Server processing* lets the server upsample streams with Cadenza's filters for browsers and phones. It's off until an admin switches it on, and each account needs the *Server processing* permission. Limits: streams at once, highest output rate and longest filter. Songs are rendered once into a disk cache (4 GB by default, *Clear cache*), the next song is rendered ahead, and seeking in a rendered song happens on your device. Listeners pick the filter, dither and rate under Settings → Playback; the badge shows *→ Cadenza 96 kHz*. The *Cadenza engine* section for your own Cadenza box stays greyed out until you link one under *Your devices*.
- **Desktop app connects through reverse proxies**: typing an address without `http(s)://` tries https first; a redirect (http → https, a sign-in portal in front of Encore) now stays inside the app instead of opening your browser and leaving a black window, and the app remembers where the server really answered. The server picker and offline pages use the Encore colours.
- **Player bar**: always shows the full layout – controls, seek bar, devices and volume – with *Nothing playing* on the left when idle; devices sit on the far right. A little taller, so the play button no longer touches the top edge. Clicking the quality badge (e.g. *FLAC 1805k*) opens the Signal path. **Space** is play/pause even right after clicking a player button (before, it "pressed" that button again – Previous restarted the song).
- **Account page**: a pencil next to your name changes your username (with a warning when there's no email on the account – the username is then the only way to sign in); *Change password* is a button that opens the form.
- **Settings**: the tab list scrolls all the way to *Diagnostics* on short windows.
- **Encore theme and app icon**: a new *Encore* theme in the logo's charcoal and cream is the default for new accounts, and the sign-in page always uses it. The Android icon now fits the launcher's circle instead of being cropped.
- **Roon**: Encore is a Roon extension now (Settings → Apps & sources → Roon, then approve it once in Roon → Settings → Extensions). Roon zones show up under *Your devices* with what's playing, transport, volume and a *Play in Roon…* search. Finds the Core on the LAN by itself; Docker users enter its address.
- **Soulseek page** – a Soulseek browser inside Encore (menu → Soulseek; shown to everyone who may pick downloads). *Search* queries the network and groups the results by user and folder with format, bitrate, size, free-slot and queue info; *Download folder* or a tick-list of files turns them into a normal request (artist/album guessed from the folder, tagged and imported like any other download). *Browse user* lists any user's shared folders. *Transfers* shows your downloads and uploads, with cancel and *Clear finished*. Works with the built-in client and with slskd.
- **Who requested it**: the album page shows *Requested by …* under the album and ` · requested by <user>` on each track's source line.
- **Home → Made for you** (once ListenBrainz is connected): your *Daily Jams*, *Weekly Jams* and *Weekly Exploration* playlists as tiles with a cover collage and an owned/total badge – play what you own, request the rest in one click.
- **For you is discovery only**: artists, albums and songs you already have are left out. When Last.fm has too little recent history the seeds fall back to 3 months → all time → what you play in Encore → the artists' top tracks, so the page always has songs.
- **Spotify imports read whole playlists** – no more stopping at 100 songs. Your own Spotify sign-in is used first, then the server's app token; the embed fallback that only knows the first 100 shows a warning in the import dialog.
- **Integrations → Test all** tests every key at once (Spotify, Tidal, Last.fm, Discogs, YouTube Music) and lists each result.
- **Discogs** help now says what it is: a personal access token from discogs.com/settings/developers, not an app.
- **Soulseek listen port from a file** (Settings → Apps & sources → Soulseek, or `SOULSEEK_PORT_FILE`): point it at gluetun's `forwarded_port` and the built-in client follows the VPN's forwarded port when it changes. `docker-compose.yml` has a commented gluetun + Encore example.
- **Android app icon**: the APK now carries the Encore icon instead of Tauri's placeholder.
- **Built-in Soulseek client** – no slskd container needed. Enter a username and password under *Settings → Apps & sources → Soulseek* (an account is created at the first sign-in), forward port 2234, and Encore searches, downloads, resumes and shares your library on Soulseek itself. Existing slskd setups keep working: the *Client* setting (Settings → Apps & sources → Soulseek → Client) defaults to *auto*, which uses the built-in client as soon as a username is set and slskd otherwise. The compose file now publishes port 2234 and comments out the slskd service.
- **Settings reorganised.** The Downloads & sources, Library/tagging and Services tabs are now one **Apps & sources** tab with a drop-down card per application, grouped as *Download sources · Library & tagging · Services*. **Playlists & sync** moved under **Scheduled tasks**, next to the sync task it belongs to. Links of the form `#/settings?s=<section>` open and scroll to that card.
- **Sign in to Tidal** (Apps & sources → Qobuz / Tidal / Deezer): Tidal downloads need your Tidal account, not an API key. The button runs streamrip's one-time device sign-in, shows the `link.tidal.com` link and waits for the approval. The Tidal Client ID help, the streamrip and yt-dlp descriptions explain what each one is for (yt-dlp handles SoundCloud and ~1,800 other sites; streamrip only Qobuz, Tidal and Deezer).
- **New desktop app, written in Rust** (Tauri) – replaces the Electron app. The download went from ~100 MB to a few MB and it uses a fraction of the memory, because it runs on the system's own webview instead of a bundled browser.
  - **Media keys and system media controls** everywhere: the Windows media overlay, macOS Now Playing / Control Center, Linux MPRIS (GNOME, KDE, `playerctl`) – play/pause/next/previous and the cover of the current song.
  - **Tray** with what's playing, play/pause/next/previous, show window, change server, quit.
  - **Server picker** that remembers every server that worked. If the saved server stops answering, the picker comes back with the reason instead of a blank page.
  - Outside links open in your browser; downloads land in your Downloads folder; one instance only; window size and position are remembered; on macOS closing the window keeps the music playing.
  - The server labels these sessions "Encore desktop on Windows/macOS/Linux" under Account → Sessions.
- **New Android app, written in Rust** – the same Tauri app as the desktop one, replacing the Java app. A small Kotlin plugin does what only Android can: the media notification with lock-screen controls, *Share → Encore* links, downloads from the web app and the session cookie for offline saving. Save for offline keeps working, the back button walks the page history, and plain-http LAN servers still work.
  - **Install note**: the APK is signed with the build's debug key (no release key is configured yet), so this first Rust version must be installed over an uninstall of the old app.
- **Rust web interface (preview).** The web app has been rewritten in Rust/WebAssembly and is served beside the JavaScript one at `/next/`. Settings → General → About has a link to try it and a link back; it shares your sign-in. The JavaScript interface stays the default until the two match.
- **Fewer GitHub Actions minutes**: nothing builds on push any more. A release builds the server and Docker image; the desktop and Android apps only when "apps" is ticked when starting the release – or on your own machine with `scripts/release-apps.sh`, which builds this OS's installer and the APK and attaches them to the release.
- Files: `Encore-Setup-<version>.exe` (Windows), `Encore-<version>-mac.dmg` (macOS, universal – unsigned: right-click → Open the first time), `Encore-<version>-linux-x86_64.AppImage` / `.deb` / `.rpm`, `Encore-android-<version>.apk` (arm64 + arm32).
