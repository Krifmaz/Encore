## Encore 2026.10.11.6-edge

- **New desktop app, written in Rust** (Tauri) – replaces the Electron app. The download went from ~100 MB to a few MB (the `.deb` is 4 MB; the AppImage bundles its own libraries) and it uses a fraction of the memory, because it runs on the system's own webview instead of a bundled browser.
  - **Media keys and system media controls** everywhere: the Windows media overlay, macOS Now Playing / Control Center, Linux MPRIS (GNOME, KDE, `playerctl`) – play/pause/next/previous and the cover of the current song.
  - **Tray** with what's playing, play/pause/next/previous, show window, change server, quit.
  - **Server picker** that remembers every server that worked. If the saved server stops answering, the picker comes back with the reason ("No Encore server answered at …", "… answered 502", "… isn't an Encore server") instead of a blank page.
  - Outside links open in your browser; downloads land in your Downloads folder; one instance only (starting it again focuses the window); window size and position are remembered; on macOS closing the window keeps the music playing.
  - Files: `Encore-Setup-<version>.exe` (Windows), `Encore-<version>-mac.dmg` (macOS, universal – unsigned: right-click → Open the first time), `Encore-<version>-linux-x86_64.AppImage`, `-linux-amd64.deb`, `-linux-x86_64.rpm`.
- The server now labels these sessions "Encore desktop on Windows/macOS/Linux" under Account → Sessions, and the remote-control device list calls them "Desktop app (…)".
