## Encore 2026.10.11.7-edge

- **New Android app, written in Rust** – the same Tauri app as the desktop one (`clients/app`), replacing the Java app. A small Kotlin plugin does what only Android can: the media notification with lock-screen controls (play/pause/next/previous, cover), *Share → Encore* links, downloads from the web app (album zips → Music/Encore) and the session cookie for offline saving.
  - Same server picker as the desktop app (saved servers, "No Encore server answered at …" when one is down, offline player when songs are saved).
  - **Save for offline** keeps working: ⋯ → Save for offline on songs and albums; with the server away the app opens its offline player.
  - Back button goes through the page's history, then to the home screen – the music keeps playing.
  - Keeps the page clear of the status bar / gesture bar / keyboard; plain-http LAN servers still work.
- **Install note**: the APK is signed with the build's debug key (no release key is configured yet), so this first Rust version must be installed over an uninstall of the old app. Settings and the saved server are asked for again once.
- File: `Encore-android-<version>.apk` (arm64 + arm32).
