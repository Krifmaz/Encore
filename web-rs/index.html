Encore needs WebAssembly

This browser blocks WebAssembly for this site, so the app cannot start. Allow it for this site and reload the page:

  • Brave: open Shields (the lion icon) for this site and allow Scripts, or set Shields down for this site.
  • Vanadium (GrapheneOS): Site settings → JavaScript JIT → allow for this site.
  • Safari with Lockdown Mode (iPhone, iPad): tap aA in the address bar → Website Settings → turn Lockdown Mode off for this site.
  • Microsoft Edge with enhanced security: open the site information (the lock icon) → turn off the enhanced security for this site, so JIT is allowed again.

Other browsers: a content blocker or a security policy that disables WebAssembly has the same effect; allow it for this site.
