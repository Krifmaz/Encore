Group listens

Several people on this server hear the same songs at the same time, each on their own device. Anyone signed in can start one and invite others with a code or a link.
Off hides every group listen entry in the apps and ends the ones that are runningDefault · env var ENCORE_GROUP_LISTEN
The host also switches “Guests can join with the link” on for their group; both must be on. Guests listen on a web page: they can't add songs or control playback, and nothing they hear is logged or scrobbled. Their access ends with the group, when they leave, or after 12 hours.Default · env var ENCORE_GROUP_LISTEN_GUESTS
They come back paused where they were, the apps join again by themselves and the host presses play. Off: a restart ends them. Group listens nobody used for 12 hours end either way.Default · env var ENCORE_GROUP_LISTEN_KEEP

Database backups

Encore copies its database once a day and before every upgrade (config/backups, or .encore-backups in the music folder when the config disk is full). Older copies are deleted at every start and after every backup; uploaded backups are never deleted.

Translated titles

Where translated and romanized titles come from, strongest first: corrections by hand, official names, romanization built into the server, DeepL with your API key, and the local model when the Translator plugin is installed. Each listener turns translations on under Settings → Language, which also shows admins the state of each source.
MusicBrainz pseudo-releases and aliases, and Apple's English names for Japanese releases. Asks MusicBrainz and Apple about the songs in your library.Default · env var TRANSLATE_OFFICIAL
Japanese kana, Korean, Cyrillic, Greek, Hebrew, Arabic, Thai and Devanagari, made on this server. Titles with kanji and Chinese titles are left to the other sources.Default · env var TRANSLATE_ROMANIZE
Translates song and album titles, never lyrics or artist names.Default · env var TRANSLATE_DEEPL
Translates and romanizes what the other sources leave, on this server, with the Translator plugin (llama.cpp and a model). It is not installed by default: install the Translator in Plugins.Default · env var TRANSLATE_LOCAL_MODEL

Surround (Dolby Atmos)

Dolby Atmos and other 5.1 and 7.1 versions of songs, in a Surround library of their own: never in the stereo lists, shuffle, playlists or stats. Admins fetch an album's or a song's Atmos version from its page (gamdl with a wrapper-v2 server); a surround file a normal request downloads lands here too. Kodi, Plex or Jellyfin can read the folder as a library of its own.
When a song or album request is done and Apple Music has it in Dolby Atmos, its Atmos version is fetched into Surround too. Needs the gamdl plugin with a wrapper-v2 server.Default · env var ENCORE_SURROUND_AUTO_ATMOS
When the Surround folder is inside the music library, writes .plexignore and .ndignore there so Plex and Navidrome libraries over /music don't show the surround albums twice. Add the Surround folder to them as a library of its own.Default · env var ENCORE_SURROUND_HIDE_FROM_STEREO

Deleting files

What happens to a file when you delete an album, a song or a file. Off: it is deleted for good straight away. On: it waits in the Trash (Settings → System → Files → Trash, on the music disk) and can be restored until the days run out.
Off: deleting an album, a song or a file deletes it for good. On: it goes to the Trash first, where you can restore it.Default · env var ENCORE_TRASH_KEEP

Download pipeline

Which sources are searched for a request, and in what order. The first one that has it wins.

Release types

Which releases Request discography, the artist pages and New releases count, like the metadata profiles in Lidarr. Song requests skip other versions (live, remix, sped up and so on) unless the song asked for is one.
Kinds to request
Request discography gets these. Each request can change them in its own panel.Default · env var RELEASE_TYPES
Skip releases that are
A release with any ticked extra is left out. Instrumental, acoustic, sped up, karaoke and covers are read from the titles. An artist can have their own: Release types on the artist’s page.Default · env var RELEASE_SKIP
A single whose song is on one of the artist’s studio albums is downloaded with that album instead of on its own (once, even when both are requested). Singles of songs on no album are downloaded as singles.Default · env var ENCORE_SINGLE_TO_ALBUM

Integrations

API keys that let users connect their Spotify, Tidal, Last.fm, Discogs and YouTube Music accounts, and power recommendations.

Media servers

Tells Navidrome, Jellyfin or Plex to rescan after new music arrives, so it shows up there right away.

Roon

Encore as a Roon extension: your Roon zones show up under Your devices with what they play, transport and volume, and “Play in Roon” starts a search result in a zone. Enable it here, then approve Encore once in Roon → Settings → Extensions.
Roon Core (or Nucleus / ROCK) on the same network. Roon 1.8 or newer.Default · env var ROON_ENABLED

Server processing (Cadenza)

Lets permitted users have their streams upsampled on this server by Cadenza (long-filter upsampling, dither and noise shaping, lossless 24-bit FLAC out). Off by default: it costs real processor time per stream. Allow users under People → Users & permissions.
Default · env var CADENZA_SERVER_ENABLED

Email

Lets Encore send password-reset and sign-in emails.

Notifications

Get a message on Discord, ntfy or any webhook when downloads finish or fail.
